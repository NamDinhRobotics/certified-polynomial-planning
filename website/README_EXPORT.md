# CP / PLANNING — portable static website

This folder contains actual HTML, JavaScript, CSS, Three.js modules, media and viewer JSON fetched directly from the public Site on 10 September 2026. It is not a DOM/text reconstruction or a new UI implementation. Original acquisition run: 34430646019; artifact: 10134346611. All imported bytes were checked against a fixed SHA-256 allowlist.

## Run locally

From the repository root: `python3 -m http.server 8000 --directory website`, then open `http://localhost:8000/`. Do not open index.html with file://: ES modules and fetch require HTTP. No npm dependencies, build tool or server backend is required; this directory is already a static production build.

## Preserved

The actual app.js, all three vendor modules, both original evidence JSON files, and every imported image/video are unchanged. The two campaigns each include scene IDs 41000–41019. Historical failures are retained. The viewer displays conic-arm repetition 0, not every one of the 80 experiment attempts. Original videos keep their original experiment scope.

## Hosting-only changes

Removed the Cloudflare challenge script injected by the original hosting layer from the HTTP HTML. Replaced the two local font rules with Google Fonts CSS requesting the same Manrope and DM Sans families. Font binaries are not bundled. All other application logic and layout CSS are preserved. The site has no runtime dependency on chatgpt.site. External Google Fonts is optional; system sans-serif is the fallback when unavailable.

## Deployment

The repository workflow .github/workflows/website-pages.yml validates file hashes, tests the viewer and publishes only website/. Initial GitHub Pages activation may require an administrator to select Settings → Pages → Source → GitHub Actions. Intended URL after successful deployment: https://namdinhrobotics.github.io/certified-polynomial-planning/ . A configured URL alone does not confirm a successful deployment.

## Tests and updates
